# Contributing

Thanks for contributing.

## Project Type
This repository hosts a static website.

- Source root: docs/
- Main page: docs/index.html
- Styling: docs/styles.css
- Browser logic: docs/main.js

## Working Agreements
Read these first:

- AGENTS.md
- .github/copilot-instructions.md

## Development Rules
- Keep runtime code plain HTML/CSS/JS.
- Do not add frameworks or build steps for site runtime.
- Use explicit relative paths with ./ in HTML references.
- Keep changes focused and minimal.

## Quality Check
Run before opening a PR:

- npm run lint

## GitHub Templates
- Create task requests with .github/ISSUE_TEMPLATE/agent-task.md
- Use .github/pull_request_template.md for pull requests
